# 网页模拟演示

## 启动与打开

在服务器的仓库目录运行：

```bash
cd ~/Echo-As-Record
uv sync --locked
uv run ear-extraction-web-demo --port 8765
```

VS Code Remote SSH 的「端口 / Ports」面板中点击「转发端口」，填写 `8765`，再打开转发后的本地地址（通常是 `http://localhost:8765`）。如果本地端口已占用，以 VS Code 显示的本地地址为准。服务仅监听服务器 `127.0.0.1`，无需开放公网端口。

不用 VS Code 时，也可以在本机终端执行 `ssh -L 8765:127.0.0.1:8765 用户名@服务器地址`，保持连接后用本地浏览器打开上述地址。Ctrl+C 停止服务；重启会清空临时数据。

## EAR 内的操作流程

1. 打开「我的活动」，查看 11 月 5 日的组会转写，当前说话人为林舟。
2. 点击「整理这段记录」，在「活动笔记」查看待办，在「提醒事项」查看待确认事项。
3. 点击「修正说话人」，在人物弹窗中确认陈默，点击「保存并更新」。笔记负责人更新，未确认提醒同步替换；页面保留更新前内容。
4. 在提醒中点击「确认提醒」，再点击「保存到本页」。当前外部提醒尚未连接，记录仅保存在当前会话，不会通知手机。
5. 在「记录动态」查看业务变化。页面不展示任务日志、模型调用、版本 ID 或原始 JSON。
6. 点击「重新开始」并确认后恢复初始记录。也可选择「忽略」提醒，或先确认提醒再修改人物，观察已确认提醒保持不变。

导航可跳转至我的活动、活动笔记和提醒事项。页面人物林舟、陈默是两个人物夹具的显示名称，不改变底层示例数据。

每个浏览器 cookie 会话独立；同一浏览器多个标签页共用场景。刷新保留状态。会话无操作两小时回收，同时最多保留 32 个会话。
