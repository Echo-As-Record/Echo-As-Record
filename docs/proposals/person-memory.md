# 人物记忆与识别证据的分层扩展

## 设计与边界

采用三层可追溯存储：①继续持有原始录音引用与转写；人物插件按活动保存有界摘要索引和来源 ID，并记录③归属及活动版本依赖；按人物、日/周/月保存聚合统计与依赖。压缩索引服务于定位，原始证据用于核对细节；不自动删除原始数据。索引上限 128 个高频词、每活动最多 1000 个片段，超过片段上限直接报错。索引并非完整记忆，检索未命中不意味着事件不存在。

这一分层借鉴 [LightMem-Ego](https://arxiv.org/abs/2607.11487) 的流式多层记忆方向；依据 [LifeDialBench](https://arxiv.org/abs/2604.11182) 和 [EgoProbe](https://arxiv.org/abs/2610.17128) 对时间与相似事件区分的关注，提供原文/摘要/混合检索和时间截止参数。这里是基于这些思路的工程实现，不声称复现论文方案或性能。

输入观察、活动关联、跨活动聚合、候选模式和查询呈现分层。共同出现、相邻轮次及条件统计均不是关系标签；候选表达也不是经确认的稳定习惯。事件消费者只读③归属，写入属于插件的派生数据，不将插件画像反向写入核心。版本依赖、重判结果和原始证据允许追查与修正；更正从日桶传播到周/月桶。具体入口、激活范围、恢复及限制见 [habit 说明](../../services/habit/README.md)。

## 集成前待对齐

- ③字段、局部说话人到人物的契约及识别系统如何使用上下文；当前离线词项基线不生成归属，也不能代表声纹识别效果。
- 运行时注册、权限、单写者、订阅恢复、⑤联调，以及自动处理新数据与人工授权历史重建的边界。
- 真实使用的数据授权、保留和删除机制；独立评估习惯和社交推断的可靠性。真实样本测试和部署本次按用户要求跳过。
